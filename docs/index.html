display-visual · macOS

画面を、紙にする。

全アプリの上に微細な紙ノイズ・暖色・減光を重ねて、発光画面のギラつきを抑える常駐アプリ。目の疲れを減らし、集中を長持ちさせます。

⬇ ダウンロード（.dmg） GitHub で見る →

macOS 13+ ・ 無料 ・ MIT ライセンス。開発者は npm i -g paperlike-overlay && paper-overlay start でも。

インストール

  1. ダウンロードした PaperOverlay.dmg を開く
  2. PaperOverlay.app を Applications フォルダへドラッグ
  3. 初回だけ Finder で右クリック →「開く」（未署名アプリの許可）
  4. メニューバーに 📄 が出たら完了。⌘⌥P でオン/オフ
未公証のため初回のみ警告が出ます。右クリック→「開く」、または システム設定 → プライバシーとセキュリティ → このまま開く で一度許可すれば以降は普通に起動します。

できること

🧻 紙ノイズ

乗算で重ねた微細な粒。脳が「紙」と誤認し、ピント調節がゆるみます。

🔆 暖色・減光

青色光カットとバックライト減光。夕方以降や暗所の刺激を下げます。

⌨️ ⌘⌥P

どのアプリからでも即オン/オフ。メニューバーからは強さも調整。

🚀 ログイン時起動

チェック一つで自動起動。設定は保存され次回も復元。
